## Overview

Stremit helps AI builders discover tools, build stacks, run AI agents, and share with the community.

**Live:** https://stremit.io

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Backend | Python 3.11, Flask 3.x |
| Database | PostgreSQL via SQLAlchemy |
| Frontend | Jinja2, Tailwind CSS, Alpine.js |
| AI | Anthropic Claude API |
| Email | Resend |
| Payments | Paddle / Gumroad |
| Hosting | Railway |
| Search | PostgreSQL full-text + FAISS semantic |

---

## What You Can Do

- Discover AI tools for different workflows and use cases.
- Build and organize AI stacks.
- Run AI agents from a community-focused platform.
- Share tools, stacks, and workflows with other AI builders.
